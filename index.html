Como redefinir a senha:
A senha fica no Firebase Authentication do cliente, não aqui. Para redefinir:
1. Abra o Console do Firebase do projeto deste cliente
2. Vá em Authentication → Users
3. Encontre o e-mail, clique nos 3 pontinhos → Redefinir senha
