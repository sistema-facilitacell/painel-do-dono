🔐 Gerar senha do Painel

Digite a senha que você quer usar no Painel do Dono. Esta página gera o "código embaralhado" dela — é isso que vai no arquivo, não a senha em si. Tudo acontece aqui no seu navegador; nada é enviado para lugar nenhum.
⚠️ Use uma senha forte: pelo menos 12 caracteres, misturando letras, números e símbolos. Como o painel ficará público, senhas curtas (como só números) são fáceis de descobrir.
O que fazer com esse código:
1. Copie o código acima
2. Abra o arquivo painel-dono.html num editor de texto
3. Procure a linha que começa com const SENHA_DONO_HASH =
4. Substitua o código que está lá pelo que você copiou (entre as aspas)
5. Salve o arquivo. Pronto — agora o painel usa sua senha nova!
